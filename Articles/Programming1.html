Learning to Program can be broken into three stages,

Stage 1 : Basics

Stage 2 : Algorithms

Stage 3 : Selecting Programming Language and adapting



Basics

Anything between ( ) is a condition

Anything between { } is statement(s)



Variables – Are those words in a that store a value and are identified by a name given

Keywords – Are words specific to a programming language that already have a meaning

Operators – Are those words/ sybmols that do an operation ( eg. Sol = 5 ADD 7 )

Decisions – Are words/ symbols that make decisions ( eg. IS 5>7 )

IF – IF ( 5>7 ) DO { 5+1 }

IF-ELSE – IF ( 5 > 7 ) DO { 5+1 } ELSE { 5-1 }

Loops – Are statements that repeat a certain task

FOR – FOR X times { Solution = Solution + 1 }

WHILE – WHILE ( Solution > 0 ) { Solution - 1 }

DOWHILE – DO { Solution + 1 } WHILE ( Solution < 100 )
