About

It has been in development since 2019, when i got access to Github Student privileges and has seen a lot of revisions including going for Jekyll and even testing out BootStrap which as you can see, Failed. And ended up using LibreOffice to create the initial deployments which were then updated in Gnome Boxes, because the LibreOffice docs were not SEO optimized and had a lot of unneeded metadata. This is the current version of the website, still being updated in Gnome Builder ( I like the looks ) and the ability to view live preview of the website as it is being modified. and since i'm stil bound by the "I like Puzles" on homepage, I've added a Easter Egg in this website so i can motivate you to go through the entire website to find it.

Features

  • File size of less than 500KB
  • Uses all SVG graphics
  • Hosted on Github Pages and Cloudfare CDN ( beta.* )
  • SEO Optimized
  • WebApp Supported
  • Has its own APK and Appimage ( F#ck Windows and MacOS )
  • All pages are fully compatible with browser accessibility
  • Will run on every single device, tested on W3M and Kindle to Debian 12
  • Domain by Google Domains
  • NameServer by Cloudfare
