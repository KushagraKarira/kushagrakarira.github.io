[ GUIDE ] Packing for Travel

This article covers the list for a 7 Day travel, i made another 30 Day travel list but it is under test.

This is from trial and error from my experience of going home from Ahmedabad, but with some modifications based on weather of destination i have taken this to 10+ cities

You may add or delete items based on your preference and choices

Note to myself : Make these amazon links and add a the reasoning on hover.

  • Backpack ( 30 – 40 L, trolley bags suck )

    • Laptop ( to get the work done, Lenovo Thinkpads and Dell XPS are good )

    • Earphones ( boAt Bassheads 105 with USB C to Aux, bluetooth battery dies just before the audio book concludes )

    • Small Notebook and Pen ( A5 dotted notebooks are okay, Reynolds Jetter or uniball jetstream are my companion )

    • Kindle ( Optional – From using the most basic model, they are good to spend time )

    • Compression Cube

      • 3 Tees – ( My favorites are Henley T-shirts from Max, go for black or dark grey color )

      • Jeans - ( Blue - Regular Fit )

      • Track Pants with zipper ( Dark grey or black )

      • 2 Socks ( Testing out the no-show type for their reduced volume, go for executive if there are mosquitoes )

    • Multi tool ( Optional – Had my bus break down, having a plier saved the day )

    • Spoon / Spork ( Would have suggested chopsticks for their versatility but they are not as culturally understandable, these are great when the cuppa comes without fork )

    • Piezo Lighter ( Optional – is helpful as a source or light or heat )

    • USB Cable and Charger(s) ( Depending on your phone and laptop go for a Duracell C to C cable and 60W PPS C collapsible charging adapter with US to EU attachment )

    • Power Bank ( 10000 mAH or the 18650 adapters )

    • Other Cables ( Optional – I’ve found myself needing Ethernet, Aux and HDMI cables )

    • Game ( Optional – When traveling with a group, card games are good way to spend time )

    • Eateries ( Avoid sugary foods )

      • Use a refillable steel bottle with wide opening ( no plastic or insulated bottles )

      • Energy bars/ Biscuits ( get the ones with fat and salt )

  • Phone ( My carry is Mi A2 because of its Android One )

  • Watch ( Recommended, get a Casio Digital watch that will last a decade )

  • Wallet ( Cards, Cash equivalent to 30% or more of your transport | 10x1, 20x2, 50x1, 100x2, 200x1, 500x1 | & paperclip )

  • Keys ( don’t forget them )

  • Optional / Weather dependent

    • Glasses

    • Wind Cheater / Windbreaker ( These are extremely lightweight and are okay against light rain as well )

    • Hoodie with zipper ( can be layered with windbreaker for better thermal insulation )

    • Gloves ( Needed while driving scooter in mornings )

    • Carabiner ( to attach anything to your backpack )

  • First Aid ( Optional, refer to a doctor for personalized dosage )

    • Aspirin ( 200mg, headaches and heart attacks )

    • Antacid ( Helps prevent vomit and acidity )

    • Paracetamol ( For cold and fever )

    • Ibuprofen ( Will either fix the pain eventually )

    • Band-aids ( it was a must have while exploring forests )

    • Elastic Bandages ( do I need to explain )

    • Isopropyl / IPA 70%

    • Hydrogen Peroxide 30% ( Cheaper and more versatile than regular antiseptic )

    • Safety Pins ( there are time when jeans tear apart )

    • Printed proscription for ongoing medication
